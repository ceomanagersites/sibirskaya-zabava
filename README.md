# Сибирская забава — сайт

Одностраничный сайт бани с бассейном и гостевого дома в Лесной поляне, Красноярск.
Статичные HTML, CSS и JS без сборки: файлы можно открыть на любом хостинге, включая GitHub Pages.

## Как устроено

```
index.html              вся страница: тексты, цены, отзывы, контакты
404.html                страница «не найдено»
favicon.svg             иконка вкладки (треугольное окно)
assets/css/style.css    дизайн: цвета и шрифты в начале файла (:root)
assets/js/main.js       сезоны на первом экране, «Что внутри», сборщик заявки, меню, карта
assets/img/             фото в WebP, по две ширины каждого
assets/og.jpg           картинка для превью ссылки в мессенджерах (1200×630)
assets/apple-touch-icon.png
```

## Как посмотреть у себя

```powershell
python -m http.server 8080
```

Затем открыть http://localhost:8080.

## Где что менять

- **Тексты, цены, услуги, отзывы, вопросы** — в `index.html`, всё по разделам с комментариями
  (`<!-- 3. Два формата -->` и т. д.). Цены встречаются в двух местах: карточки «Баня» и «Гостевой дом»
  и ответ «Сколько стоит?» в вопросах.
- **Телефоны и мессенджеры** — в `index.html` (поиск по `79135387733`) и в начале `assets/js/main.js`
  (объект `CONTACT`: WhatsApp, Telegram, координаты для карты).
- **Часы работы** — в `index.html` (поиск по `10:00`) и в блоке `application/ld+json` в начале файла.
- **Фото** — положить новый файл в `assets/img/` с тем же именем или поменять путь в `index.html`.
  Пропорции: первый экран 3:2 (`-wide`) и 3:4 (`-tall`), остальные 4:5.
- **Цвета** — переменные в начале `assets/css/style.css`. Оранжевый `--ember` используется только
  для кнопок бронирования и маршрута.

## Как работает бронирование

Сервера и базы нет. Форма «Забронировать» собирает текст заявки и открывает WhatsApp
(+7 913 538-77-33) или Telegram (@sib_zabava) с готовым сообщением. Заявка уходит, только когда
посетитель сам нажмёт «Отправить» в мессенджере, и приходит в эти чаты. Если Telegram не подставил
текст, есть кнопка «Скопировать текст».

## Публикация

Сайт рассчитан на GitHub Pages: ветка `main`, папка `/ (root)`. Все пути относительные,
поэтому работает и в подпапке `имя.github.io/репозиторий/`.

**Индексация закрыта** (`<meta name="robots" content="noindex, nofollow">` в `index.html`):
это черновик. Когда появится свой домен:
1. убрать эту строку;
2. добавить `<link rel="canonical" href="https://домен/">` и полный адрес в `og:image`;
3. добавить сайт в Яндекс Вебмастер и Google Search Console;
4. указать адрес сайта в карточках 2ГИС и Яндекс Карт.
